project day-to-day — not curated for reading. Kept here for provenance rather
than as part of the documentation reading path. See [`../README.md`](../README.md)
for the actual reading path.

Three files here are operational rather than historical, and are worth finding:

- [`MAINTENANCE-AND-KNOWN-ISSUES.md`](MAINTENANCE-AND-KNOWN-ISSUES.md) — what breaks on
  its own (the Monday collector vs. the model-CI gates, Render free-tier limits), what is
  deliberately unfinished, and what each would cost to fix.
- [`AWS-MIGRATION-NOTES.md`](AWS-MIGRATION-NOTES.md) — how and why to redeploy this on
  ECS Fargate later, as a learning exercise rather than a hosting change.
- [`SESSION-PROCESS-ERRORS-2026-08-26.md`](SESSION-PROCESS-ERRORS-2026-08-26.md) — how the
  2026-08-26 release was sequenced badly, and the rules that prevent it next time.
